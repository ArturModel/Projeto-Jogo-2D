# Cofre de arquitetura — Santa Rita

Abra **esta pasta** (`docs/architecture-vault`) no Obsidian como cofre.

- `manual/`: documentação curada de C1/C2, arquitetura, fontes e trabalho com IA; preservada nas exportações.
- `generated/`: notas derivadas do código atual e `graph.canvas`, regeneráveis. Ctrl+G abre as conexões entre notas no Obsidian.
- [Estado atual](../ai-memory/CURRENT_STATE.md) e [operação](../GRAPHIFY-OBSIDIAN-OPERACAO.md).

O grafo local é estrutural/AST; notas de documentos antigos não são fatos novos. Código, cenas, decisões atuais e evidências citadas prevalecem. Atualize com `scripts/graphify-refresh.ps1`/`.sh`, valide com o script correspondente. Obsidian não precisa estar aberto para atualizar os arquivos.
