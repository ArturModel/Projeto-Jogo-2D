# Trabalho com IA — C1/C2

Siga AGENTS.md na raiz. Leia [estado atual](../../ai-memory/CURRENT_STATE.md) e as notas pertinentes, use Graphify para localizar símbolos e confirme o fluxo nos fontes. Se o índice faltar/estiver defasado, registre e investigue por busca direcionada.

Após mudanças estruturais de código: refresh + validate, atualização das notas afetadas e memória de projeto. Windows usa scripts `.ps1`; Bash usa `.sh`. [Comandos, versão e limites](../../GRAPHIFY-OBSIDIAN-OPERACAO.md).

C2 até Bocha está implementado; capítulos não são barreiras de mundo. Preserve Escola adiada, mapa/Bíblia, retornos a C1, lanterna F, slots explícitos e save manual no orelhão. O progresso do autor prevalece sobre resumos importados. Testes antigos não certificam uma alteração nova, e QA não equivale a aprovação artística.

Não instalar hooks sobre configurações existentes implicitamente. Não enviar código/segredos para extração remota nem indexar saves/mídias/caches. Grafo/cofre são auxiliares locais fora do Player.
