Leia critérios em `Docs/Producao_Artistica_Execucao.md` e a matriz do capítulo afetado. Use Unity MCP local quando disponível; conferir instância e projeto antes de modificar a cena. Preserve trabalho não salvo e nunca usar slots pessoais para QA.

Associe evidência ao pedido: vídeo para pernas/quadros, captura normal para composição, zoom real para leitura, input real para interação, save isolado para persistência. Teste proximidade, revisitas, portas, pausa, foco, resolução e retorno a C1 quando afetados. Fixture/repositicionamento devem estar declarados.

Verificações estáticas e regras de Bocha não comprovam qualidade visual. Compare antes/depois com enquadramento equivalente e exercite materiais/iluminação na build final. Não encerrar com scripts não executados. Atualize o plano e registre o que passou, falhou e depende de avaliação humana.
